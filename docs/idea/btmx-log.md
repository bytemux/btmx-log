# btmx-log
A journal app where you write messages to your future self, offload thoughts from your head, track the goals you set, and build trust in yourself.

The concept is original, but features can be borrowed from
- Apple Journal
- Mindsera

# MVP
- Screen 1: A list of chats, like in Telegram. The user can create a new one: "Create new CHAT". There is search by name.
- Screen 2: The user can open a chat and send a message. Messages scroll upward, everything like in Telegram.

Under the hood:
- Message storage. Unicode text / emoji, stored locally on the phone (for now just with iCloud sync).
- Settings -> Export to Markdown or JSON; About (version, commit hash, author).

# Post-MVP

## Key features
#### Quick thoughts
CHATS TAB. The user can save quick thoughts as a short message in the selected CHAT. Text only.
- By default, a message goes to the "Inbox" chat. Below the input field there is an optional picker for where to send it (like the model picker in Claude mobile): a chat and/or a goal. The user can skip it; then the message goes to "Inbox", and the topic can be chosen later.
- Any message has an optional "remind me" date (field `remind_at`; set it in the picker below the input field, or by long-pressing a sent message). On that date a notification arrives with the old message. Scenarios:
  - time capsule: a letter to yourself for January 1
  - postponed thoughts: "reread this in a month"
  - a big decision: "taking offer X, expecting such-and-such" + remind in 6 months to compare with the result
- Messages whose "remind me" date falls in the current month are also shown in the monthly review.
- Example chats (topics):
  - Impulses (for example: "remembered how great it is to be in a relationship, I need to work on this") can be linked to a goal from the list. Then the entry does not stay just a fantasy: it goes into the goal and into the monthly review.
  - Principles: your own rules and conclusions ("Let's finish things") + one line of context on why this came up now. Will show up later in the 'Memories / On this day' section at the top of the app, like Google Photos reminds you of old times by topic, etc.
  - Relationships: thoughts about interactions with people
  - Topics without analysis (topics with analysis have an icon)
    - sport
    - jokes
    - party tricks
    - the user can create their own; it gets an id and can be renamed
- Backfill (a separate script, not an app feature): think_tank in Telegram and other chats

#### Journal
GOALS TAB. At the start, limit it to the monthly scheme only.
- Entries can be monthly, quarterly and yearly. An entry has 2 text fields (Vibe; Goals) + a list of goals.
- Vibe: a free text field; later, preset questions generated by AI, up to 3.
- The list of goals is a checklist with statuses:
  - 🟢 Done
  - 🟡 In progress
  - ⚪ Not started
  - 🔵 Let go — consciously dropping a goal is not a failure. It builds trust in yourself more than endless postponing.
  - Example: - [🟢 Done] Plant a tree; - [🟡 In progress] Go on 10 dates; - [⚪ Not started] Learn to do a handstand
- Each goal can have a comment. The UX is an open question here.
- A notification once a month/quarter/year invites the user to record the result for the past period and carry goals over to the new one or set other goals. The invitation opens the form for the current period right away, and after the OK button it offers to fill in the next one.
- Quick thoughts for this month are pulled into the monthly review; this links the two tabs. They are shown as "Thoughts of the month". Tapping it opens a virtual chat: messages filtered by date.
- If a goal was carried over, the number of carry-overs is shown on it. Tapping the number shows a tooltip with the date the goal was first set (for example: x2 months, March 2026).
- On the third carry-over the app asks: "Rephrase, shrink, or let go?"
- A goal has a stable ID for its whole life: "Go on 10 dates" in March and in April is one goal (one `goal_id`) and two periods, not two different goals. A long press renames it and keeps the id. This ID holds:
  - the carry-over counter and the date the goal was first set
  - links from chat messages (otherwise the links break on every carry-over)
- Goal screen:
  - Heatmap: how often the user wrote entries about this goal
  - Fake chat: a list of all messages linked to the goal (filter by `goal_id`); it looks like a normal chat
- Backfill (a separate script, not an app feature): Joplin Diary

## Analytics with AI
- Remembers which people you mention and which emotions are linked to them. A screen with statistics: a list of people; each person has an emoji and a few words about which emotions they bring into your life.
- "Ask Your Journal" searches your whole history for patterns; emotion detection rolls into long-term analysis of mood shifts across weeks, months, and seasons; and recurring topics are detected automatically.
  - Example queries to show the user: What emotions does Vanya cause in me? What worried me in 2024? How many trips to Europe did I take, and how many of them did I like? Top 3 things that were on my mind in recent years. Examine my long-term thought patterns. How do I usually feel on Sundays? Which topics repeat in my principles, and when? The user can add their own queries and pick from a list so they don't have to type them every time.
- Smart "Memories" (idea from the Caching chapter of "Algorithms to Live By": memory works like a cache; what you need more often comes up more often):
  - new principles and entries are shown more often, old ones less often (following the forgetting curve)
  - if the user marked a principle "still works", show it less often; if it has not resonated for a long time, offer to archive it
- Draft of the month's results (idea from Computational Kindness: don't ask open questions, offer a concrete choice):
  - before the monthly review, AI prepares a draft from quick thoughts and entries linked to goals: a suggested status for each goal, a short "Vibe" of the month, and what it suggests to carry over
  - the user does not write from scratch, only confirms or edits
  - wherever possible, instead of an empty field: chips and ready options (statuses, "rephrase / shrink / let go", ready questions for "Vibe")

## Hints for the user
- Fields say what is meant to go into them.
- Per-section hints when tapping the (?) button inside a tab. For example, for goals, hints on which criteria are needed (for example: measurable). The same (?) holds the wizard for creating topics, in the topics tab.

### Hints: "Principles" chat
- Write when a phrase resonated because of what is happening to you now. Beautiful quotes from others with no reason behind them can be skipped.
- Add one line of context: why this came up now. A year later, without context, the phrase will say nothing. Example:
  ```
  Let's finish things
  — abandoned my third pet project at 80%
  ```
- If a principle is about a specific goal, link it to that goal with the picker below the input field.
- Repeats are normal: what you write to yourself again and again shows what you are struggling with right now.
- Once a year, mark which principles still work and which no longer resonate.

### Hints: goals
- "Let go" is not a failure. Consciously dropping a goal is better than carrying it over endlessly.
- If a goal is carried over 2–3 times in a row, try to rephrase or shrink it.
- An impulse ("I need to work on X") does not move you toward a goal by itself. Link it to a goal; then it goes into the monthly review.

## Optional features
- Letters to your future self with a delivery date (works through the "remind me" date, see Quick thoughts)
- Bucket list. These are goals with no deadline, for the whole life. (Probably in the Journal)
- Emotion map. At minimum, a reference section on which emotions exist at all. It helps people who don't understand what they feel. Interactive, if needed (attach to a message, etc.)
